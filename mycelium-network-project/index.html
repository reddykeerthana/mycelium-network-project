Biological Mycelium vs. Computer Networks

Fungal mycelium exhibits remarkable decentralised intelligence—continuously adapting its topology to route resources around physical damage. Here is how biological structures translate into network engineering.

🍄

Decentralised Topology

Just as mycelium grows without a central brain, modern resilient computer networks eliminate single points of failure by interconnecting nodes in a multi-path mesh.

⚡

Adaptive Path Selection

Mycelium reinforces high-efficiency channels and abandons congested or dry paths—mirrored by our AI cost-weighted Dijkstra route-selection algorithm.

🔄

Self-Healing Rerouting

When soil disruption severs a fungal hypha, nutrients immediately divert through cross-linked anastomoses—just as our simulator bypasses failed links automatically.

Engineering Proposal & Architecture

Project Documentation

Comprehensive breakdown of the problem statement, objectives, methodology, technology stack, and expected engineering outcomes.

01

Problem Statement

Conventional static or tree-based computer networks often rely on rigid primary routes and centralised controllers. When a physical cable is severed, a relay experiences heavy congestion, or a link fails unexpectedly, packet loss occurs and manual reconfiguration is frequently required—leading to downtime and poor fault tolerance.

02

Objectives

  • Model a multi-node computer network inspired by the redundant, decentralised branching of mushroom mycelium.
  • Implement an actual graph-based AI route-selection algorithm (weighted Dijkstra) considering distance, link health, and availability.
  • Simulate real-time link failures with automatic alternative route discovery and packet retransmission.
  • Provide an intuitive, browser-based interactive web visualisation for educational and engineering demonstration.
03

Methodology

  1. Biological Modeling: Map fungal hyphae, junctions, and nutrient flow to weighted undirected graph structures.
  2. Graph Construction: Build a 12-node, 24-edge resilient mesh topology with distance and congestion metrics.
  3. AI Pathfinding: Execute Dijkstra's shortest-path algorithm across active edges to minimise total transmission cost.
  4. Fault Injection & Recovery: Allow dynamic link deactivation, trigger instant topology re-evaluation, and animate packet rerouting.
04

Tools & Technologies

HTML5 Semantic Structure CSS3 Glassmorphism & Grid JavaScript (ES6+) Interactive SVG Graphics Graph Data Structures Dijkstra's Shortest-Path Algorithm RequestAnimationFrame Engine

Engineered as a zero-dependency client-side web application requiring no backend server or external runtime.

05

Expected Outcomes

Resilient Communication Continuous data delivery even when multiple primary branches are severed.
Real-Time AI Transparency Clear visualisation of hop counts, route weights, and live failover decisions.
Interactive Demonstration A presentation-ready web tool bridging biological inspiration and network engineering.
